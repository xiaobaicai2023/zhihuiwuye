# -智慧物业管理系统-
物业、智慧物业、智慧社区、物业管理系统、小区物业版、智慧物业管理平台、物业小程序、报修小程序、智慧物业后台、物业缴费系统、小区物业管理、物业缴费小程序、小区APP
功能说明
工作台、基础数据、收费看板、缴费记录、待办事项 看板、缴费数据、合同统计、工单统计、能耗统计、数据大屏 项目管理、楼座管理、房屋管理、业主管理、访客管理、通行管理 物业服务、业主通知、问卷调查、活动报名、业主积分、积分明细 工单管理、工单分派、工单指派、工单进度、师傅接单、工单跟进 资产管理、客户管理、合同管理、添加合同、到期续签、到期提醒、合同预览 智能巡检、设备管理、点位管理、巡检计划、巡检任务、巡检报表 缴费管理、缴费控制台、收费标准、收费绑定、收费模板、账单操作、账单通知 物联模块、门禁管理、远程开门、模拟离线、启停管理、通行记录、授权记录 监控管理、监控设备、监控墙、1画面、4画面、9画面、告警事件 其他、党建活动、党员管理、意见反馈、广告管理、参数配置

客户端
移动端uniapp开发，支持打包H5、小程序、APP 
技术栈
后台服务 springboot+mybatisplus+mysql
